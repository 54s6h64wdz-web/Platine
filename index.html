Paramètres
Normaliser le volume par défaut

Chaque son est monté à −0,3 dB de crête (exports trop faibles). Un réglage manuel du volume reste prioritaire.

Loop activée par défaut

Sur tous les sons dont le BPM est connu : dans le nom, d'après les autres versions, ou détecté. Si tu coupes la Loop sur un son, elle reste coupée.

Détecter le BPM automatiquement

Pour les sons sans BPM dans le nom (affiché « ≈ »). Corrige-le avec ÷2, ×2 ou en le tapant dans Edit → Loop.

Dossiers synchronisés

Sur iPhone, une app web ne peut pas garder l'accès à un dossier : à chaque synchro, choisis le dossier dans Fichiers puis touche « Ouvrir ». Seuls les nouveaux sons et ceux modifiés sont importés. Tu peux aussi choisir un seul sous-dossier (une semaine) : il sera rangé avec son dossier parent.
